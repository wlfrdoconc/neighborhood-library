# Neighborhood Library Application

Built a Java console-based application that lets anyone manage a neighborhood library's inventory.
Users of the program can view available books, check out books, check in books, and return books through an interactive menu.

# Features 
1. **Interactive Menu:** Allows users to navigate through the program with interactive commands (1, 2, and X).
2. **View Available Books:** Displays all books currently available in the library.
3. **View Checked Out Books:** Displays books that have been borrowed and the names of their borrowers.
4. **Check Out Books:** Allows users to select an available book using its ID and enter their name.
5. **Check In Books:** Allows users to return borrowed books using their book ID.
6. **Exit Application:** Allows users to exit the application.
